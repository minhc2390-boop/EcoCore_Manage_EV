JOBCT – Giao diện lọc và sắp xếp việc làm

Cách chạy:
1. Giải nén file ZIP.
2. Mở thư mục job_filter_ui.
3. Nhấp đúp vào index.html để mở bằng Chrome/Edge.
   Hoặc mở thư mục bằng VS Code và chạy Live Server.

Chức năng demo:
- Lọc việc làm theo công ty.
- Lọc việc làm theo quận/huyện.
- Kết hợp hai bộ lọc.
- Sắp xếp theo ngày đăng, lương, tên công việc.
- Xem hồ sơ công ty, chi nhánh và việc làm đang tuyển.

Lưu ý:
Đây là giao diện Frontend minh họa, dữ liệu hiện đang viết mẫu trong JavaScript.
Chưa kết nối Backend hoặc Database. Tên chi nhánh và dữ liệu tuyển dụng cần được
đối chiếu/cập nhật theo dữ liệu thực tế của dự án trước khi đưa vào sử dụng.
